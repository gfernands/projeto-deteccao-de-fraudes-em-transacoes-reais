# projeto-deteccao-de-fraudes-em-transacoes-reais
Modelo de Machine Learning capazes de identificar transações fraudulentas em cartões de crédito.  Foi utilizado um dataset com 284.807 transações reais, contendo 30 variáveis preditoras e uma variável de classificação (Class), na qual:  0: transação legítima.  1: transação fraudulenta.
